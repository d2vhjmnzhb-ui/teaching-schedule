v86 — แก้กดบันทึกแล้วดูเหมือนไม่มีอะไรเกิดขึ้น (ใช้บน iPad)
สาเหตุที่พบ: ข้อความ "บันทึกแล้ว" ไปแสดงท้ายหน้าแก้ไข ไกลจากปุ่ม และแถบ Cloud ลอยทับขอบล่างจอ
เพิ่มปุ่ม "บันทึกฉบับร่าง" และ "พิมพ์ / บันทึก PDF" ไว้บนสุดของหน้าแก้ไข
บันทึกแล้วมีแถบข้อความเด้งบนจอ ปุ่มเปลี่ยนเป็น "บันทึกแล้ว ✓" และตรวจอ่านกลับว่าเก็บข้อมูลจริง
ถ้าบันทึกไม่สำเร็จ จะแจ้งสาเหตุเป็นแถบสีแดง และดาวน์โหลดไฟล์สำรองของฉบับนั้นให้อัตโนมัติ
เว้นที่ท้ายหน้าไม่ให้แถบ Cloud บังปุ่ม
ยังคงของ v85: ชื่อไฟล์ PDF = ชื่อเรื่อง
