ระบบหนังสือเรียนฟรี v51 — ปรับจาก v50

การติดตั้ง
1. สำรองข้อมูลตารางสอนจากเว็บเดิมก่อนอัปเดต
2. แตก ZIP และอัปโหลดไฟล์ทั้งหมดในโฟลเดอร์นี้ทับใน repository เดิม รวม vendor, books-v51.js และ book-templates.js
3. เปิด URL เดิมด้วยเบราว์เซอร์/เครื่องเดิม แล้วรีเฟรช ห้ามล้างข้อมูลเว็บไซต์
ข้อมูลตารางสอนใช้ชื่อที่เก็บเดิม ไม่ถูกย้ายหรือล้างโดยส่วนหนังสือใหม่

การใช้งาน
เลือกปี/ภาคเรียน/แผน → ตรวจหนังสือเดิมหรือ Import → ตรวจ/จับคู่ → ยืนยัน → กรอกวันที่ จำนวนผู้เรียน หัวหน้าแผนก → สร้างชุดเอกสาร
หากภาคเรียนไม่มีแผน ให้เพิ่มแผนหรือนำเข้าในเมนูแผนการเรียนก่อน การสลับภาคเรียนไม่เปลี่ยนชื่อแผนเดิม
หนังสือเดิมที่ดึงมาเป็นข้อมูลอ้างอิง ต้องตรวจและยืนยันอีกครั้งก่อนส่งออก

สิ่งที่เพิ่ม
- แยกการเลือกหนังสือตามแผน ตัวเลือก 1–3 พร้อมเหตุผลและประวัติการเปลี่ยน
- นำเข้า Excel .xlsx / Word .docx ที่มีตาราง / CSV แบบตรวจรายการก่อนยืนยัน
- หัวคอลัมน์ที่ต้องมี: รหัสวิชา, ชื่อหนังสือ (หรือชื่อวิชา), ผู้แต่ง, สำนักพิมพ์, ราคา
- การนำเข้าจะเพิ่มตัวเลือกสำรอง ไม่เขียนทับเล่มที่เลือก ถ้าเกิน 3 ตัวเลือกจะหยุดให้แก้ไขก่อน
- ลากไฟล์เข้าได้ .xls รุ่นเก่าต้องแปลงเป็น .xlsx และ Word สแกนเป็นภาพยังอ่านไม่ได้
- Dashboard ความครบและราคาต่อชุด/ยอดตามจำนวนผู้เรียน/วงเงิน
- สำรองและคืนข้อมูลหนังสือเป็น JSON แยกจากตารางสอน
- ส่งออกบันทึกข้อความ, สมอ.1 รายวิชา, สมอ.2, สมอ.3 รายสำนักพิมพ์, สมอ.4 เป็น DOCX ใน ZIP
- เอกสารอิงต้นฉบับ ปวช.1–3 ไม่สร้างแบบฟอร์ม ปวส. ขึ้นเอง
- ตรวจจำนวนแถวและโครงสร้างก่อนส่งออก เกินแถวจะหยุด ไม่ตัดข้อมูลหรือย่อตัวอักษร

ข้อจำกัดที่ต้องทราบ
ส่วนเว็บยังไม่มี Microsoft Word rendering engine จึงยังไม่ใช่ระบบเทียบภาพทุกหน้าอัตโนมัติ และยังไม่ได้สร้าง PDF คู่กันโดยอัตโนมัติ
โครงสร้าง OOXML ของแต่ละฟอร์มคงเดิม แต่ข้อความใหม่/ฟอนต์ต่างเครื่องทำให้การตัดบรรทัดและแบ่งหน้าเปลี่ยนได้
ต้องเปิดใน Microsoft Word ด้วยฟอนต์ TH SarabunPSK และ TH SarabunIT๙ ตามต้นฉบับ ตรวจทุกหน้าและลายเซ็นก่อน Export PDF
ข้อมูลการอนุญาต/กระดาษ/สี/ขนาดที่ไม่กรอกจะเว้นว่าง ไม่คัดข้อมูลของหนังสือเก่ามาใช้แทน
ผลการพิจารณา ผลตรวจรับ และผลใช้หนังสือเว้นไว้ให้ผู้มีหน้าที่ประเมิน
ชื่อผู้บริหาร/กรรมการที่ไม่ได้เป็นครูผู้สอนหรือหัวหน้าแผนกยังคงตามต้นฉบับ ให้ตรวจสอบก่อนใช้
ข้อมูลหนังสือ v51 อยู่ในเบราว์เซอร์ ไม่ได้รวมในปุ่มบันทึก Cloud ของระบบตารางสอน ใช้ปุ่มสำรองข้อมูลหนังสือก่อนย้ายเครื่อง
ยังไม่ได้เพิ่มการคัดลอกปีการศึกษาและชุดเอกสารทุกชั้นพร้อมกัน ปุ่มสร้างทั้งชุดทำงานกับแผนที่เลือก

ผลทดสอบและสถานะ
ทดสอบ Chromium: เปิดเว็บไม่มี JavaScript error, ดาวน์โหลด DOCX/ZIP ได้, นำเข้าแบบ preview ไม่เขียนข้อมูลก่อนยืนยัน, สลับอันดับหนังสือ, ประวัติ, โหลดซ้ำข้อมูลยังอยู่, สลับภาคเรียนเดิม, และป้องกันข้อมูลเกินแถว
ตรวจว่าข้อมูลครู ห้อง รายวิชา และคาบเรียนไม่เปลี่ยนจากการทำงานส่วนหนังสือ
เรนเดอร์เอกสารตัวอย่าง ปวช.1 ด้วย LibreOffice และฟอนต์ทดแทนเพื่ออ่านตรวจ: สมอ.4 มีลายเซ็นต่อหน้าใหม่ จึงยังไม่ผ่านเงื่อนไขไม่ผิดเพี้ยนทุกหน้า ต้องตรวจด้วย Word และฟอนต์ต้นฉบับก่อนใช้จริง
รุ่นนี้ยังไม่ใช่ Document Engine สมบูรณ์ตามข้อ 1 ยังขาดตัวจัดหน้าและการเปรียบเทียบภาพอัตโนมัติ และยังไม่มีการยืนยันผลบน Safari/iPad
