College System v115 — อัปเดตจากไฟล์ v114 ที่แนบมา

วิธีติดตั้ง: แตก ZIP แล้วนำไฟล์และโฟลเดอร์ทั้งหมดขึ้นแทนชุดเดิม โดยคงโครงสร้างเดิม รีโหลดหน้าเว็บหลังอัปโหลด
ข้อมูลใช้งานอยู่ในเบราว์เซอร์/Cloud ไม่ได้อยู่ใน ZIP นี้ ควรส่งออกข้อมูลสำรองก่อนเปลี่ยนรุ่น

แก้ไขตารางครูและงานพิมพ์
- ใช้ข้อมูลคาบจริงและรองรับรหัสที่เก็บต่างชนิด (ตัวเลข/ข้อความ)
- รวมคาบครูจากทุกแผนที่อยู่ปีการศึกษาและภาคเรียนเดียวกัน ไม่รวมปีเก่า
- แสดงกลุ่มเรียนรวมครบ และไม่รวมเซลล์ต่อเนื่องเมื่อกลุ่มต่างกัน
- รายวิชาที่ถูกลบหรืออ้างอิงไม่ได้แสดงข้อความแจ้งแทนช่องว่าง ไม่เดาข้อมูลที่หาย
- การรวมรายวิชาซ้ำตอนเปิดระบบย้ายรหัสอ้างอิงของคาบตามไปด้วย
- รีเฟรชตัวอย่างก่อนพิมพ์ ใช้ครูที่เลือกในหน้าพิมพ์

แก้ไขคาบเรียน
- แผงเลือกคาบ/ครู/ห้องอยู่เหนือตาราง ไม่ซ่อนในพื้นที่เลื่อนแนวนอน
- ปุ่มแก้ครู/ห้องในเซลล์พาไปที่แผงเดียวกัน
- บันทึกเฉพาะคาบที่เลือก ไม่เปลี่ยนครูตั้งต้นของทุกคาบในวิชานั้น
- ตรวจครู/ห้องชนก่อนบันทึก รวมแผนในภาคเรียนเดียวกัน

ผลตรวจระบบวิเคราะห์
ระบบเดิมค้นหาตามกฎจริง ไม่ใช่โมเดล AI และไม่ใช่ตัวพิสูจน์ว่าจัดตารางได้ดีที่สุด
พบว่าคำสั่ง v114 ถูกตัวควบคุมเก่าที่โหลดทีหลังทับ และข้อความไม่พบคำแนะนำเคยอ้างว่าตารางถูกต้องเกินหลักฐาน
รุ่นนี้เพิ่มรายงานข้อมูลอ้างอิงหาย คาบพัก/กิจกรรม ครูชน ห้องชน คาบเกิน และคาบขาด
ใช้การจำลองทั้งแผนย้ายเพื่อตรวจปลายทางทุกก้อนและวิชาที่จะลงเพิ่ม ก่อนเสนอและก่อนใช้จริง
ตรวจแผนได้แม้จัดคาบครบแล้ว และไม่ถือว่า 'ไม่พบคำแนะนำ' เท่ากับ 'ตารางสมบูรณ์'
จำกัดการค้นหา 600 รูปแบบต่อวิชา และย้ายไม่เกิน 2 ก้อนตามขอบเขตเดิม เพื่อไม่ให้ค้นหาโตเกินจำเป็น
ข้อจำกัด: ไม่รับประกันคำตอบที่ดีที่สุด ไม่ได้ค้นหาการย้ายทุกจำนวนก้อน คำแนะนำย้ายยังค้นในแผนที่เปิดอยู่ โดยตรวจการชนกับแผนอื่นในภาคเรียนเดียวกันด้วย
การปรับปรุงระยะต่อไปที่มีประโยชน์: การค้นหาใน Web Worker พร้อมยกเลิกได้ และ constraint solver สำหรับข้อมูลขนาดใหญ่

หน้าตา

- สีฟ้า/เขียว การ์ดและปุ่มใหม่ เมนูเลื่อนแนวนอนบนมือถือ เมนูด้านข้างบนคอม
- ย้ายแถบ Cloud ออกจากการลอยทับพื้นที่ทำงาน
- รูปแบบเอกสารพิมพ์แยกจากหน้าจอ
