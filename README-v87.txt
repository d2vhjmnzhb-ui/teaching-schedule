v87 — แก้พิมพ์ / บันทึก PDF ไม่ได้บน iPad
สาเหตุที่พบ: ตัวรอฟอนต์ จัดหน้า และสั่งพิมพ์ ทำงานในหน้าหลัก แต่ iPad พักหน้าหลักไว้เบื้องหลังเมื่อเปิดแท็บใหม่ จึงไม่พิมพ์
แก้โดยย้ายตรรกะทั้งหมดไปอยู่ในหน้าพิมพ์เอง และให้ปุ่ม "พิมพ์ / บันทึก PDF" สั่งพิมพ์ทันทีที่แตะ
บน iPad ไม่สั่งพิมพ์อัตโนมัติ ให้แตะปุ่มเอง (iPad บล็อกการพิมพ์ที่ไม่ได้เกิดจากการแตะ)
หน้าพิมพ์แสดงสถานะ "พร้อมพิมพ์" หรือแจ้งว่าฟอนต์โหลดไม่ครบ และมีคำแนะนำบันทึกเป็นไฟล์บน iPad
ชื่อไฟล์ PDF = ชื่อเรื่อง (คงจาก v85) • ปุ่มบันทึกและแถบแจ้งผล (คงจาก v86)
แก้เฉพาะ documents.js และเลขเวอร์ชันใน index.html
อัปโหลดทุกไฟล์รวมโฟลเดอร์ fonts ทับของเดิม แล้วปิดแท็บเปิดใหม่
