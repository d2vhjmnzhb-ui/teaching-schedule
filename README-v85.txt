v85 — แก้ส่งออก/บันทึก PDF ของระบบเอกสาร และตั้งชื่อไฟล์ตามชื่อเรื่อง
แก้เฉพาะระบบเอกสาร (documents.js) ไม่แตะตารางสอนและหนังสือเรียนฟรี
ชื่อไฟล์ PDF = ชื่อเรื่องของหนังสือ (ตัดอักขระ \ / : * ? " < > | ออกให้อัตโนมัติ)
ปุ่มพิมพ์ / บันทึก PDF ในหน้าต่างพิมพ์กดได้ทันที ไม่ค้างเป็นสีเทาถ้าโหลดช้า
ถ้าโหลดฟอนต์ไม่ครบ จะถามว่าจะพิมพ์ต่อหรือไม่ แทนการหยุดพิมพ์ทั้งหมด
ถ้าเบราว์เซอร์บล็อกป๊อปอัป ระบบพิมพ์จากหน้าเดิมให้แทน
กดบันทึกฉบับร่างแล้วแสดงข้อความ "บันทึกฉบับร่างเรียบร้อยแล้ว" ถูกต้อง (เดิมถูกข้อความอื่นทับ)
กดพิมพ์จากเมนูเบราว์เซอร์โดยตรง ชื่อไฟล์ก็ใช้ชื่อเรื่องเช่นกัน
อัปโหลดไฟล์ทั้งหมดรวมโฟลเดอร์ fonts ทับเว็บไซต์เดิม แล้วรีเฟรชหน้า (iPad: ปิดแท็บแล้วเปิดใหม่)
