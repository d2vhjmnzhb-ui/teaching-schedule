v88 — รวมการแก้กับไฟล์ v87 ของผู้ใช้
1. คงปุ่มบันทึกฉบับร่างด้านบน/ล่างและการตรวจอ่านกลับของ v87
2. เพิ่มปรับขนาด 12–24 pt การจัดแนว และระยะบรรทัดแยกแถวในเนื้อหา กด Enter เพื่อแยกแถวที่ปรับได้ ค่าถูกบันทึกในฉบับร่างและไฟล์สำรอง
3. เนื้อหาค่าเริ่มต้นชิดซ้าย ไม่ถ่างคำในบรรทัดสั้น
4. เส้นเซ็นและจุดในวงเล็บใช้เส้นโค้งจาก glyph จุดของสามฟอนต์ Sarabun ที่แนบ วาดเป็น SVG ไม่พึ่งการแทนฟอนต์ของระบบ
5. หน้าพิมพ์ทำงานได้เองตาม v87 กดพิมพ์โดยตรง ไม่รอปุ่มปลดล็อกฟอนต์
6. ปุ่มดาวน์โหลด PDF ในหน้าพิมพ์สร้างไฟล์ชื่อเรื่อง.pdf โดยตรง มีลิงก์ให้แตะซ้ำได้หากเครื่องไม่ดาวน์โหลดอัตโนมัติ
PDF ดาวน์โหลดตรงเป็นภาพความละเอียดสูงเพื่อรักษาหน้าตา จึงคัดลอกข้อความไม่ได้ หากต้องการข้อความให้ใช้พิมพ์ / บันทึก PDF ของเบราว์เซอร์
หนังสือภายนอกยังเป็น 3 ชุด ตัวอย่างหลักยังแสดงเฉพาะชุดสมบูรณ์
อัปโหลดไฟล์ทั้งหมดรวมโฟลเดอร์ fonts และ vendor ทับของเดิม แล้วเปิดเว็บใหม่
ทดสอบบน Chromium: บันทึกและเปิดใหม่จำค่าตัวอักษร, ชื่อ PDF, A4, ภายใน 1 หน้า และภายนอก 3 ชุด ยังไม่ได้ทดสอบอุปกรณ์ iPad จริง
